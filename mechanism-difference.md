# Mechanism check

Lexicon Turnstile is not a generic policy verdict or document-diff contract. Its reusable state is a bounded semantic registry. Each review compares one candidate against every currently canonical definition, produces an exclusive relation plus one canonical pointer, and changes future comparison inputs by admitting only `UNIQUE` terms. Alias routing and one same-origin conflict revision are specific to vocabulary maintenance.

It does not score, allocate, forecast, rank a queue, approve an exception, or compare text versions. The output is a composable canonical-term graph rather than a free-form assessment.
